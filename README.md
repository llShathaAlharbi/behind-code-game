# خلف الكود — مناسب أو لا؟

لعبة تفاعلية لمحطة الفايب كودينج ضمن مبادرة «خلف الكود» التابعة إلى Tuwaiq CLUB.

## طريقة اللعب

- اقرأ السيناريو واسحب البطاقة يمينًا إذا كان الفايب كودينج مناسبًا، ويسارًا إذا لم يكن مناسبًا.
- يمكنك استخدام الأزرار أو سهمَي لوحة المفاتيح.
- بعد كل اختيار يظهر التفسير، وفي النهاية تظهر نتيجتك من ثماني حالات.

اللعبة تعمل بالكامل في المتصفح؛ لا تتطلب حسابًا أو تسجيل دخول ولا تجمع بيانات اللاعبين.

## التشغيل

افتح `index.html` مباشرة، أو انشر جذر المستودع عبر GitHub Pages من فرع `main`.

## الملفات

- `index.html`: الصفحة العربية.
- `style.css` و`game.js`: التصميم ومنطق اللعبة.
- `robot.css` و`robot.js`: إطلالة الروبوت المتحرك.
- `assets/`: الشعارات والخطوط وصورة الروبوت.

الروبوت رسم بمظهر ثلاثي الأبعاد متحرك داخل الصفحة. يمكن إيقاف الحركة من الزر أعلى الصفحة، كما يُراعى إعداد تقليل الحركة في الجهاز.

الرسالة التعليمية: الاستخدام المناسب يعتمد على حساسية البيانات ومخاطر التطبيق، ولا يغني توليد الكود عن تجربته ومراجعته.
